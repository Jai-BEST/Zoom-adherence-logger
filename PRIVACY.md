# Privacy Notice

The Undertaker stores Zoom session timestamps locally in the user's Chrome profile and does not transmit data to any external service.

The extension reads rendered Zoom meeting page text locally to match configured recorder names. This can include displayed chat text, but page text is not stored or transmitted. It does not capture audio or video or access credentials, cookies, browsing history, Salesforce data or Rippling application data.

Users may export their locally stored timestamp history as a CSV file. The exported file remains under the user's and organization's control.

Manually entered session names or chat/case references are also stored locally and included in CSV exports.
